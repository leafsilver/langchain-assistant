# 青枫编程社 Python 工程训练营手册

## 基本信息

本期训练营代号为 LEAF-2026。

每周三晚上 19:30 在综合楼 B204 教室进行线下答疑。无法到场的成员需要提前在学习群中请假。

## 作业提交

所有项目作业必须提交到 GitHub。提交截止时间为每周日 22:00。

仓库必须包含 README.md、依赖配置文件和合理的 .gitignore。真实的密码、API Key 和 Token 不允许提交到仓库。

## 设备借用

社团提供测试笔记本和开发板。普通成员每次最多借用 7 天，归还前需要删除个人账号和本地敏感配置。

设备出现故障时，不允许自行拆机，应联系设备管理员小林。

## 结业要求

完成命令行 API 客户端、FastAPI 后端和 LangChain 智能助手三个项目，且最终项目通过现场演示，才能获得结业证明。
